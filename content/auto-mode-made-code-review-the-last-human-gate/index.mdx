Anthropic made auto mode the default in Claude Code this month. I think that's the right call, but it moves human judgment somewhere specific. Code review is now the last point where a person looks at what the agent did before it ships, and it carries more weight than it did last week.

## Humans were bad at approving commands

In Anthropic's own study, human reviewers caught 13.6% of dangerous commands. The classifier caught 89%.

We spent two years treating the approval prompt as the safety layer. Most of us were pressing enter.

## Why auto mode is still the better default

The approval prompt trained people to stop reading. When every tool call asks for permission, saying yes becomes a reflex. I'd rather have a classifier that reads every tool call than a tired engineer clicking approve for the 40th time before lunch.

## What Anthropic said about production

The same announcement says classifiers cannot eliminate risk, and that you should keep human review for production changes. I agree with both halves. The approval prompt is gone, and review is now the only human check left between an agent's output and production.

## Did your review process keep up?

Teams on auto mode ship around 25% more PRs. Ask your team whether the review process got 25% better to match. You're getting more diffs, written faster, with less human attention at the moment they were written, so the reviewer is doing a bigger share of the work than before. If review still looks the way it did when a person typed every line, it's probably the weakest part of the pipeline now.
