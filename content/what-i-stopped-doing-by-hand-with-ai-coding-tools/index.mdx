These are the things I stopped doing by hand in 2026, ranked by how much I miss them. Overall I ship faster and learn narrower, and I'm working on the second part.

## Writing boilerplate

Miss level: zero. CRUD endpoints, DTOs, test scaffolding. The agent writes it and I review it. I haven't typed a migration file since spring.

## Googling regex

Miss level: zero. I describe what I want and read the result carefully, because regex confidence is how production incidents are born.

## Writing the first draft of tests

Miss level: low. The agent's tests are honest about the happy path and lazy about the edges, so I add the edges. It still saves me an hour a day.

## Reading documentation start to finish

Miss level: high, honestly. I ask and get the answer, but I've lost the accidental learning. I used to find gold three paragraphs below the thing I searched for. Now I only find what I ask about, and I don't know what I no longer know.

## Debugging alone at midnight

Miss level: complicated. Rubber ducking an AI at 1am works disturbingly well, and I get unstuck faster. I also solve fewer things in the shower the next morning, and the shower solutions were usually better designs.
